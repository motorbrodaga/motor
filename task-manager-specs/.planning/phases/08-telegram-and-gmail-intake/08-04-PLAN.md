# 08-04: Store Source Labels Without Source Links

## Objective

Add durable optional source-label support to the task model without storing links to original Telegram messages or Gmail emails.

## Context To Read

- `.planning/phases/08-telegram-and-gmail-intake/08-CONTEXT.md`
- `.planning/REQUIREMENTS.md`
- `zadachnik-app/prisma/schema.prisma`
- `zadachnik-app/src/lib/tasks/task-validation.ts`
- `zadachnik-app/src/lib/tasks/task-queries.ts`
- `zadachnik-app/src/features/tasks/task-types.ts`
- `zadachnik-app/src/features/tasks/TaskCard.tsx`
- `zadachnik-app/src/app/api/tasks/route.ts`
- `zadachnik-app/src/app/api/tasks/[id]/route.ts`

## Implementation Tasks

1. Add nullable `sourceLabel` storage to the `Task` model and create a Prisma migration.
2. Expose `sourceLabel` in task query mapping and `TaskView`.
3. Allow task creation and update APIs to accept a sanitized optional source label.
4. Reject or ignore source URL/link fields in this phase; do not add `sourceUrl`, `messageId`, or `emailId` persistence.
5. Display the source label quietly on task cards and task detail when present.
6. Add validation tests for source-label length, trimming, optional absence, and no link-field persistence.

## Acceptance Criteria

- Imported tasks can store `from Gmail` or `from Telegram Motorcodex_bot`.
- Normal manually created tasks still work with no source label.
- No original message/email links are stored.
- Task cards can show the source label when present.

## Verification

- Run Prisma migration generation/checks.
- Run task validation and task API tests.
- Run `npm run typecheck`.
