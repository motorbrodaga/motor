# 08-01: Implement Telegram Motorcodex_bot Selection Flow

## Objective

Let the user explicitly open Telegram import from "More", view up to 20 latest `Motorcodex_bot` messages, and choose one source item for task preparation.

## Context To Read

- `.planning/phases/08-telegram-and-gmail-intake/08-CONTEXT.md`
- `.planning/phases/08-telegram-and-gmail-intake/08-RESEARCH.md`
- `AGENTS.md`
- `scripts/telegram-account-import-all.js`
- `zadachnik-app/src/app/(app)/more/page.tsx`
- `zadachnik-app/src/app/api/assistant-capture/interpret/route.ts`

## Implementation Tasks

1. Add a Telegram import entry under the new import area reachable from "More".
2. Create a server-side Telegram provider/helper that uses the existing local GramJS setup without logging secrets or session content.
3. Fetch only `Motorcodex_bot` messages for the MVP and hard-cap displayed choices at 20.
4. Return sanitized choices with compact preview text, timestamp, and source label `from Telegram Motorcodex_bot`.
5. Add a manual paste fallback in the Telegram screen when live Telegram access fails or returns no usable messages.
6. Ensure selecting a Telegram item passes only the chosen item into the shared intake confirmation flow.

## Acceptance Criteria

- Telegram import is reachable from "More", not from the quick capture button.
- User can choose from no more than 20 latest `Motorcodex_bot` messages.
- Manual paste fallback is available and uses the Telegram source label.
- No task is created by merely opening Telegram import or viewing choices.
- No `.env` or Telegram session content is printed, copied, or committed.
