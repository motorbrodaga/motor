# 08-03: Convert Selected Telegram/Gmail Source Into Confirmed Task Cards

## Objective

Use the selected Telegram message, Gmail email, or manual paste text to prepare an editable task card, then create a normal task only after explicit save.

## Context To Read

- `.planning/phases/08-telegram-and-gmail-intake/08-CONTEXT.md`
- `.planning/phases/03-assistant-capture/03-CONTEXT.md`
- `.planning/phases/03-assistant-capture/03-02-SUMMARY.md`
- `zadachnik-app/src/lib/assistant-capture/interpret-task-capture.ts`
- `zadachnik-app/src/features/capture/QuickCapturePanel.tsx`
- `zadachnik-app/src/features/tasks/TaskForm.tsx`
- `zadachnik-app/src/app/api/tasks/route.ts`

## Implementation Tasks

1. Add a shared intake draft type with source text, source label, provider kind, and sanitized preview.
2. Reuse or extend the assistant interpretation helper so source content becomes a summarized task draft rather than a verbatim copy.
3. Render a confirmation card showing title, date, category, importance, optional description, and source label.
4. Support edit, cancel, and save actions on the confirmation card.
5. Save confirmed intake tasks through the normal task API with the source label attached.
6. Keep optional fields empty when interpretation cannot infer them and the user still explicitly saves.
7. Add tests proving cancel creates no task and save creates exactly one task.

## Acceptance Criteria

- Selected Telegram content is summarized into task content instead of copied verbatim.
- Selected Gmail content prepares a task card before save.
- Confirmation card supports edit, cancel, and save.
- Save persists a normal task with the correct source label.
- No source item can create a task without explicit save.
