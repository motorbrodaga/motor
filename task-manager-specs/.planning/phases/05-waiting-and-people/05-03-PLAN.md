# 05-03: Add Soft Waiting Follow-up

## Objective

Satisfy the one-week follow-up requirement for `я жду` tasks without turning Phase 5 into the full weekly review system. The reminder should be soft and local to the waiting screen.

## Context To Read

- `.planning/phases/05-waiting-and-people/05-CONTEXT.md`
- `.planning/phases/05-waiting-and-people/05-RESEARCH.md`
- `zadachnik-app/src/app/(app)/waiting/page.tsx`
- `zadachnik-app/src/features/tasks/TaskCard.tsx`
- `zadachnik-app/src/lib/dashboard/focus-ranking.ts`
- `zadachnik-app/src/lib/dashboard/dashboard-sections.ts`
- `zadachnik-app/tests/dashboard-focus-ranking.spec.ts`
- `zadachnik-app/tests/dashboard-sections.spec.ts`

## Implementation Tasks

1. Use `waitingSince` to detect `я жду` tasks that have no response date, no due date, and have waited at least seven days.
2. Add a soft check-in label or subgroup on the waiting screen for those tasks. Keep copy calm and Russian-only.
3. Do not add push notifications, Dashboard pressure, or weekly-review surfacing in this phase.
4. Update daily focus ranking so only tasks with `waitingDirection = waiting_for_me` and a response due date can influence daily focus later; do not boost all person tasks.
5. Add tests for the seven-day threshold, including tasks newer than seven days and tasks with dates.
6. Run a mobile visual smoke check for `/waiting` after seeded data includes both directions and an overdue check-in.

## Acceptance Criteria

- `я жду` tasks without a date get a soft check-in signal after seven days.
- The check-in behavior is visible on `/waiting`, not pushed into Dashboard or notifications.
- Tasks with a normal date or response date do not get the undated one-week check-in label.
- Waiting logic remains derived from person plus direction.
- The UI remains readable on phone-sized viewports.

## Verification

- Add focused unit tests for the follow-up helper.
- Add or update Playwright coverage for `/waiting` mobile display.
- Run Dashboard ranking/section tests to verify temporary Phase 4 waiting shortcuts are gone.
- Run `npm test` and `npm run build` in `zadachnik-app`.
