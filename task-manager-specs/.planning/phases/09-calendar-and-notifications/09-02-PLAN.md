# 09-02: Add Calendar Action To Task Detail

## Objective

Let the user deliberately add a task to the iPhone calendar from the task detail page, with clear handling for missing date or time.

## Context To Read

- `.planning/phases/09-calendar-and-notifications/09-CONTEXT.md`
- `.planning/phases/09-calendar-and-notifications/09-RESEARCH.md`
- `.planning/phases/09-calendar-and-notifications/09-01-PLAN.md`
- `zadachnik-app/src/app/(app)/tasks/[id]/page.tsx`
- `zadachnik-app/src/features/tasks/TaskForm.tsx`
- `zadachnik-app/src/app/api/tasks/[id]/route.ts`

## Implementation Tasks

1. Add a calendar panel/action on the task detail page only.
2. If the task already has date and time data, allow creating/updating the linked calendar event directly.
3. If the task has a date but no time, show a compact choice: all-day event or choose exact time.
4. If the task has no usable date, ask for a date/time before linking.
5. Let the user choose whether to include description and notes in the calendar event.
6. After linking, show the subscription/feed status and a copyable calendar feed URL or instructions to subscribe.
7. Keep labels Russian-only and mobile-first, with no heavy technical explanation in the main flow.

## Acceptance Criteria

- Calendar controls are visible on task detail and absent from list cards.
- A task can be linked as all-day or timed.
- Missing date/time is handled before creating the link.
- The calendar event uses the task title and can include description/notes.
- The user can understand that the feed must be subscribed on iPhone for updates.
