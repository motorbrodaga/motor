# 09-06: Add Calendar Subscription Copy Fallback

## Objective

Fix the calendar panel so a denied clipboard permission shows a calm manual-copy fallback instead of surfacing `Failed to execute 'writeText' on 'Clipboard'`.

## Context To Read

- `.planning/phases/09-calendar-and-notifications/09-UAT.md`
- `.planning/phases/09-calendar-and-notifications/09-02-SUMMARY.md`
- `zadachnik-app/src/features/tasks/TaskCalendarPanel.tsx`
- `zadachnik-app/tests/calendar-notifications-flow.spec.ts`

## Implementation Tasks

1. Catch errors from `navigator.clipboard.writeText`.
2. Show the subscription URL in a selectable readonly field when clipboard copy fails or when clipboard is unavailable.
3. Change the status message to plain Russian copy, for example: `Не удалось скопировать автоматически. Ссылка ниже, ее можно выделить вручную.`
4. Keep successful copy behavior unchanged.
5. Add or update a focused test that covers the visible manual fallback state.

## Acceptance Criteria

- Clicking `Скопировать подписку` never shows a raw browser exception to the user.
- If clipboard permission is denied, the calendar panel displays the subscription URL in a visible field.
- The user gets clear Russian copy explaining manual copy.
- Existing calendar link and regenerate behavior continue working.

- Run `npm run typecheck`.
- Run `npm run test:e2e -- calendar-notifications-flow.spec.ts`.
