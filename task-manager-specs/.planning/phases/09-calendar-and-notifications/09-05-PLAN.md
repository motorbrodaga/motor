# 09-05: Schedule And Send Direct But Soft Reminders

## Objective

Deliver real push notifications for the morning review and individual task reminders while keeping copy direct, useful, and non-punitive.

## Implementation Tasks

1. Add reminder scheduling fields or a reminder model for individual task reminders.
2. Add morning review notification time settings with a sensible default and optional disable.
3. Implement a minimal scheduled sender that finds due notifications and sends Web Push messages without duplicates.
4. Route morning notifications to the dashboard and task reminders to the task detail page.
5. Use a short Russian copy set with direct wording such as "Пора открыть задачи", while avoiding shame or alarm.
6. Add sent/dismissed tracking so the same reminder is not repeatedly pushed after delivery.
7. Add test coverage for preference filtering, due reminder selection, duplicate prevention, and notification payloads.

## Acceptance Criteria

- Morning review notifications can be enabled, disabled, and sent at the configured time.
- Individual task reminders can be enabled, disabled, and sent when due.
- Notification copy is direct but not punitive.
- Delivered notification payloads open the right app destination.
- Duplicate sends are prevented for the same scheduled reminder.
