# 06-01: Implement Weekly Review Resurfacing Foundation

## Objective

Create the weekly review foundation: week boundaries, open-task eligibility, no-due-date and no-do-date resurfacing, and any minimal state needed to keep "returns once per week" behavior calm and predictable.

## Context To Read

- `.planning/phases/06-soft-reviews/06-CONTEXT.md`
- `.planning/phases/06-soft-reviews/06-RESEARCH.md`
- `.planning/REQUIREMENTS.md`
- `zadachnik-app/prisma/schema.prisma`

- `zadachnik-app/src/lib/tasks/task-queries.ts`
- `zadachnik-app/src/features/tasks/task-types.ts`

## Implementation Tasks

1. Add a weekly review helper module under `src/lib/review/`.
2. Implement Monday week-start calculation and review-window helpers.
3. Define the base query for open, unarchived, not-done tasks.
4. Implement no-due-date and no-do-date groups.
5. Decide whether a tiny review-state table is needed for "seen this week"; if needed, add Prisma schema and migration with the smallest possible shape.
6. Keep this foundation independent from Dashboard focus confirmation state.
7. Add focused tests for week boundaries and no-date grouping.

## Acceptance Criteria

- Tasks without due dates can be surfaced as a weekly review group.
- Tasks without do dates can be surfaced as a weekly review group.
- The logic is based on weekly review boundaries and does not mutate Dashboard behavior.
- The user can still open review manually even when it is not Monday.
