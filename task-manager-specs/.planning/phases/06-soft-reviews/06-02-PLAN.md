# 06-02: Add Stale Forgotten And Waiting Review Groups

## Objective

Extend the weekly review helper with stale tasks, forgotten tasks, and waiting-without-movement items so the review covers the main ways tasks get lost.

## Context To Read

- `.planning/phases/06-soft-reviews/06-CONTEXT.md`
- `.planning/phases/06-soft-reviews/06-RESEARCH.md`
- `.planning/phases/05-waiting-and-people/05-VERIFICATION.md`
- `zadachnik-app/src/lib/review/weekly-review.ts`
- `zadachnik-app/src/lib/waiting/waiting-tasks.ts`
- `zadachnik-app/prisma/schema.prisma`

## Implementation Tasks

1. Implement stale task detection using no changes for 7 days.
2. Implement forgotten task grouping using a conservative threshold chosen by the executor and documented in code/tests.
3. Implement waiting-without-movement using Phase 5 waiting fields, especially `waitingSince` and waiting direction.
4. Ensure completed and archived tasks never appear in review groups.
5. Add tests for stale, forgotten, and waiting-without-movement thresholds.
6. Keep group names and reasons soft and Russian-ready for the UI layer.

## Acceptance Criteria

- Weekly review can show forgotten tasks.
- Weekly review can show stale tasks with no changes for 7 days.
- Weekly review can show waiting items without movement.
- Grouping logic is deterministic and covered by tests.

## Verification

- Run review helper tests.
- Run waiting follow-up regression tests if affected.
