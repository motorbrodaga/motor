# Phase 6: Soft Reviews - Discussion Log

**Date:** 2026-06-03
**Phase:** 6 - Soft Reviews

## Questions Asked

### Weekly Review Format

**Question:** How should the Monday weekly review feel?

**Options presented:**
- Soft list - one calm page with grouped tasks.
- Step-by-step review - process groups one by one.
- Like Dashboard - similar to morning panel but separate.

**User selected:** `1-1` - soft list.

### Review Actions

**Question:** What can the user do with tasks directly from the weekly review?

**Options presented:**
- Quick actions - keep, assign date, mark important, complete, open.
- Only open task.
- Full editing in review.

**User selected:** `2-1` - quick actions.

### Review Tone

**Question:** How should the review bring forgotten tasks back into attention?

**Options presented:**
- Very soft - no pressure.
- Neutral - dry groups and counters.
- Persistent - visible warnings.

**User selected:** `3-1` - very soft.

## Decisions Captured

- Weekly review is a soft grouped list.
- Review page should be separate from Dashboard.
- Quick actions should be available where practical.
- Tone should be pressure-free and calming.

## Deferred Ideas

- Notifications and reminders outside the page.
- Full inline editing.
- Analytics or history.
