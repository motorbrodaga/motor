# 06-03: Build Weekly Review Screen And Category Accumulation

## Objective

Replace the `/review` placeholder with the actual weekly review page: a soft grouped list with category accumulation and practical quick actions.

## Context To Read

- `.planning/phases/06-soft-reviews/06-CONTEXT.md`
- `.planning/phases/06-soft-reviews/06-RESEARCH.md`

- `zadachnik-app/src/features/tasks/TaskQuickActions.tsx`
- `zadachnik-app/src/app/globals.css`

## Implementation Tasks

1. Replace `/review` placeholder with a server-rendered weekly review page.
2. Show Monday-oriented review framing while keeping the page manually accessible any day.
3. Render soft sections for forgotten, stale, no due date, no do date, waiting without movement, and category accumulation.
4. Add quick actions directly on review task rows/cards where practical: leave/keep, set date, mark important, complete, and open.
5. Add calm empty states for each group and for the whole review.
6. Add category accumulation view showing categories with open task counts and recent examples.
7. Keep the UI mobile-first, Russian-only, and visually separate from Dashboard.

## Acceptance Criteria

- User can open weekly review from `/review`.
- Weekly review shows required groups and category accumulation.
- Tasks in review offer quick actions without full inline editing.
- Empty review states are calm and useful.
- Review page is readable on phone-sized screens.

## Verification

- Add Playwright coverage for populated and empty review states.
- Add mobile smoke coverage for `/review`.
- Run focused review tests.
