# 07-02: Add Completion Statistics By Count, Category, And Time

## Objective

Add lightweight statistics to completion history using the same completed-task dataset: task count, category distribution, and total entered actual time.

## Context To Read

- `.planning/phases/07-completion-history/07-CONTEXT.md`
- `.planning/phases/07-completion-history/07-RESEARCH.md`
- `.planning/phases/07-completion-history/07-01-PLAN.md`
- `zadachnik-app/src/lib/history/`
- `zadachnik-app/src/features/tasks/task-formatters.ts`
- `zadachnik-app/src/app/(app)/review/page.tsx`
- `zadachnik-app/src/app/(app)/more/page.tsx`

## Implementation Tasks

1. Extend the history helper with a statistics builder.
2. Count completed tasks for the current visible period.
3. Compute category distribution, grouping uncategorized tasks under a soft Russian label.
4. Sum `actualMinutes` only when it is present.
5. Format total time in a compact Russian-friendly form.
6. Add a compact statistics area above or alongside the day-based list without replacing the list.
7. Add tests for count, category distribution, uncategorized grouping, and total actual time.

## Acceptance Criteria

- Completion history shows completed task count.
- Completion history shows category distribution.
- Completion history shows manually entered actual time spent when present.
- Statistics do not hide or replace the completed task list.
- Empty statistics do not imply failure or judgment.
