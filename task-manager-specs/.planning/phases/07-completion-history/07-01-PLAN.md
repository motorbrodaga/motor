# 07-01: Build Completion History Queries And Views

## Objective

Create the foundation for completion history: reusable completed-task queries, day-based grouping, a dedicated history screen, and entry points from both "More" and review.

## Context To Read

- `.planning/phases/07-completion-history/07-CONTEXT.md`
- `.planning/phases/07-completion-history/07-RESEARCH.md`

- `zadachnik-app/src/app/(app)/review/page.tsx`
- `zadachnik-app/src/lib/review/weekly-review.ts`

## Implementation Tasks

1. Add a `src/lib/history/` helper module for completed-task retrieval and day grouping.
2. Query tasks with `completedAt != null` and `archivedAt == null`, ordered newest first.
3. Implement local day buckets for today, yesterday, and this week.
4. Create a dedicated history page under the app shell.
5. Render completed task rows with title, category, completion day, and optional actual time if present.
6. Add a clear entry point from `More`.
7. Add a soft entry point from the review page without making history the main review content.
8. Add focused tests for grouping and the screen route.

## Acceptance Criteria

- User can view completed tasks for today.
- User can view completed tasks for the current week.
- Completed tasks are listed by day buckets, not mixed into active task lists.
- The history page is reachable from both "More" and review.
- Empty states are calm and Russian-only.
