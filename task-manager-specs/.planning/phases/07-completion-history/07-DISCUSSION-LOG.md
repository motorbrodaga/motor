## History Placement

| Option | Description | Selected |
|--------|-------------|----------|
| Separate "History" screen in More | Keeps history as a quiet reference surface. | |
| Inside Review | Keeps review and remembered work together. | |
| Both, primary place in More | Gives access from both review and More while keeping a clear home. | yes |

**User's choice:** Both review and More, with the primary place in More.
**Notes:** This keeps history available during reflection without crowding the daily dashboard.

## Actual Time Entry

| Option | Description | Selected |
|--------|-------------|----------|
| Prompt when completing | Asks "how long did it take?" immediately after completion. | |
| Only later on history screen | Avoids interrupting completion but may hide the action. | |
| Do not ask immediately; provide "Add time" | Keeps time tracking optional and visible. | yes |

**User's choice:** Do not ask immediately; provide a separate "Add time" action.
**Notes:** This matches the soft-product direction from prior phases.

## Completed Task Display

| Option | Description | Selected |
